# 🌐 软包装外贸英语（Soft Packaging Foreign Trade English）

一站式外贸英语学习网站，纯静态单页应用，无需安装任何依赖、无需后端、无需联网即可运行（发音朗读使用浏览器内置语音合成）。

> 重点强化 **听说能力**：真人发音朗读（TTS）、逐句跟读并**录音对比**、听写训练、角色扮演对练。
>
> 同时强化 **实操能力**：导航「🧭 实操 SOP」把订单确认后的内部流转、单证制作、订舱报关、货款回收做成可勾选清单，每一步都配可直接发出去的英文。

> **导航版块（信息架构）**：顶部导航已从 11 个平铺入口收敛为 **5 个分组 + 首页**（桌面端为下拉分组，移动端为纵向手风琴）：
> **📚 学习**（课程）· **🎤 口语听说**（听说训练 / 辨音 / 四维实战）· **🧭 外贸实操**（实操 SOP）· **🤖 AI 陪练**（AI 对练 / ⚙️ 计划·打卡·手册）· **🃏 记忆与测验**（单词卡 / 测验 / ⚠️ 易错点）。
> 首页「学习路径」另按 **三阶段**（商务基础 → 通用外贸 → 软包装专业·实操）递进分组，替代纯平铺目录。

## 🚀 快速开始

### 方式一：双击一键启动脚本（推荐）

双击 `启动外贸英语网站.bat` —— 自动检测 Python/Node、后台启动服务器、打开浏览器访问 `http://localhost:8000`。
关闭弹出的启动窗口即自动停止服务器。此方式下语音（发音/评测/语音输入）功能完整可用。

### 方式二：直接双击打开（最快，仅浏览）

双击 `index.html`。适合浏览课程、搜索、背单词、做测验；**注意**：`file://` 协议下 Chrome 会禁用语音识别/TTS/录音，听说功能不可用。

### 方式三：手动本地服务器（听说功能最完整）★推荐

在 `外贸英语` 目录打开 PowerShell / CMD，运行：

```bash
python -m http.server 8000
```

然后浏览器访问：<http://localhost:8000>

（无 python 时用 Node：`npx serve .`；或用 VS Code 的 Live Server 插件）

## 🚀 部署与分享（GitHub Pages / Cloudflare Pages）

> 部署到带 **HTTPS** 的静态托管后，PWA 才能被「安装到桌面 / 离线打开 / 分享给同事」——这是让它真正跑起来的关键一步。本站纯静态、零构建，无需任何打包。

### 方式 A · GitHub Pages（推荐，含自动发布）

1. **建仓库**：在 GitHub 新建一个仓库（如 `softpackaging-english`，设为 **Public** 或 Private+Pages 付费，Public 免费托管）。
2. **推代码**（把 `外贸英语` 目录变成仓库并推送）：

   ```bash
   cd "外贸英语"
   git init
   git add .
   git commit -m "init: 软包装外贸英语 + 实操SOP (PWA/FSRS/Azure评测/vosk/闯关)"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/softpackaging-english.git
   git push -u origin main
   ```

3. **开 Pages**：仓库 → `Settings` → `Pages` → **Source 选 `GitHub Actions`**（用根目录已附带的 `.github/workflows/pages.yml` 自动发布，推 push 即更新）。
4. **访问**：发布完成后 `https://<你的用户名>.github.io/softpackaging-english/`，用浏览器打开（HTTPS）→ 地址栏出现「安装」图标，点一下即可**安装到桌面、离线打开**；把链接发给同事即可分享。
5. **离线语音依赖（可选）**：`models/` 被 `.gitignore` 忽略（40MB，避免把仓库撑大）。若要「全离线识别」，把 `vosk-model-small-en-us-0.15/` 手动上传到托管根目录（或用 Pages 的网页拖拽上传），或直接删除 `.gitignore` 里的 `models/` 一并提交。

### 方式 B · Cloudflare Pages（免 GitHub、可拖拽）

1. 登录 Cloudflare → **Workers & Pages → Create → Pages**。
2. 选择 **Connect to Git**（连你的仓库，自动构建）或 **Direct Upload**（把 `外贸英语` 里的所有文件拖上去）——本站零构建，`Build command` 留空、`Build output directory` 填 `.`（或直接上传）。
3. 部署完成即获得 `https://<项目>.pages.dev`（HTTPS）→ 同样可装 PWA、分享。

### 部署后注意

- **必须用 `https://` 访问**，PWA 与 `navigator.serviceWorker` 才生效（`file://` 双击打开会跳过 SW，属正常）。
- 改动任何页面资源后，把 `sw.js` 顶部的 `CACHE` 版本号 +1，用户才会自动刷新出新版本（已在站内做「新版本待刷新」提示）。
- 访问统计（可选，免 Cookie、不影响离线）：加一行 [GoatCounter](https://www.goatcounter.com/) 或 Cloudflare Web Analytics 的 `<script>` 到 `index.html`。
- 上传的 `models/`（离线 vosk 模型）约 40MB，若不需要「完全离线」，可不上传；浏览器在线识别 + Azure + 系统人声仍可用。

### 🔁 学习闭环与内容校验

- **成绩闭环**：四维口语实战的每次成绩自动写入本地进度 `eval4`，会展示在**首页「🎯 四维口语实战」概览卡**（最近一次的四维条 + 最近 5 次列表），并在**本周 AI 学习报告**中按场景汇总各维度均值，指出短板与下周的专项方向（术语发音 / 流利度 / 应答准确性 / 表达逻辑）。
- **内容校验闸**：因为行业术语（laminating 覆膜、corona treatment 电晕、peel strength 剥离强度、MOQ 等）是精确且高风险的，网站对 AI 生成的行业内容加了两道提示：
  1. **四维评测**：AI 对拿不准的行业表述会输出「⚠️ AI 对以下行业表述不太确定，建议到术语库/正式资料人工核对」；
  2. **AI 陪练**：在教练规则里开启「行业术语人工核对提示」后，导师遇到没把握的术语会标注 `[请人工核对术语：xxx]`，让你在真实商务使用前再确认一遍。

### 🎙️ 语音能力（VPN / PC 代理场景最佳）

你有常开 VPN（国内直连、国外走代理），这是**使用浏览器在线语音的最佳场景**：

- **发音（三音源）**：
  - **浏览器语音（默认）**：系统自动优先选择高音质在线神经网络人声。**最省事的是用 Microsoft Edge**：在 Edge 设置 → 语音 → 首选发音设为 Online (Natural)，即可获得接近真人的微软神经人声，免费、无需 Key。
  - **Azure 语音（推荐给固定用 Chrome 的用户）**：在设置里选「Azure 语音」并填入订阅 **Key + Region**（在 Azure 门户创建 Speech 资源即可）。质量与 Google 在线语音同档甚至更自然，且为正规接口、浏览器可直接跨域调用；免费额度够日常练习。失败自动回退浏览器语音。
  - **Google 在线**：第三方免费端点，常被 Google 封禁而失效，已标为“不稳定”，不再推荐。
- **浏览器在线语音识别**（跟读评测 🎯、AI 陪练 🎤）：依赖 Google。你的 VPN 让 Chrome 可访问时即自动生效，评测自动重试网络抖动。
- 若某次识别报"网络错误"：多为 Chrome 未走代理 → **Chrome 设置 → 系统 → 开启「使用系统代理」**，或让 VPN 全局接管；也可先点「🔍 诊断语音」确认 Google 是否可达。
- **兜底**：Android 无法在线识别时，可聚焦输入框按 <kbd>Win</kbd>+<kbd>H</kbd> 用系统听写，或以「逐句跟读 + ● 录音对比 + 听写训练」为主练习听说。

> 评测算法会**逐词分级**：精确命中全分、近似/错拼（如 forward≈fourd）给部分分、漏读标红——帮助你精准定位哪个音没发对。

### 🗣️ AI 口语陪练

1. 点击顶部导航「**AI 陪练**」；
2. 在「模型设置」中选择服务商（推荐 **DeepSeek**，支持浏览器跨域），填入 **Base URL**、**模型名**、**API Key**（如 `https://api.deepseek.com` / `deepseek-chat` / 你的 `sk-...`），点「保存设置」；
3. **教练规则（推荐）**：默认已套用教练式预设——先交流、不逐句打断；每 3 轮集中复盘 2 个最明显的错误、给出 1 个更自然的表达和 1 个值得重复的句子；卡住时只给关键词提示，不替你说完整答案；结束给出 10 分制评分与下次重点。可在「🎯 教练规则」里改「纠错节奏 / 语速 / 等我说完再回应」，「⤵ 一键教练预设」随时一键还原。
4. 从「**选择一个场景开始对练**」点一个外贸真实场景（展会接待、询盘报价、商务谈判、电话沟通、售后客诉、视频会议、物流、机场/酒店）填入输入框并发送，再开始全英文角色扮演；也可直接用英文或中文开口。
5. 对话中导师会：
   - 全程用英文交流，你说中文会先翻译成英文再接话；
   - 按你设定的「纠错节奏」纠错（可每 3 轮复盘，或立刻纠正，或全程不纠正统一总结）；
   - 遇到新词按「【新词: 单词 | 释义 | 例句】」格式标注，**自动收录**到页面下方的学习词汇表；
   - 结束给出 **10 分制评分 + 下次练习重点**；
6. 每条回复可点「🔊 朗读」「🌐 翻译」「➕ 今日错题」；点回复里的英文单词可手动加入词表；**语音对话闭环**：点 🎤 用浏览器在线识别把你说的英文填入输入框 → Enter 发送（VPN 场景下效果好）；不生效时用系统听写（Win+H）。
7. **今日错题 · 下次复习**：聊完点「🪄 让 AI 提炼本场错句」把 2 个明显错误 + 1 个更自然表达加入清单，或手动把 AI 回复加入；**第二天先复述它们**（🔊 朗读 → 跟读），掌握了点 ✓ 移除。口语不是靠收藏资料增长，而是靠把说不顺的句子重新说顺。
8. **🎯 四维评分本场对话**：场景对练中想评测自己说得好不好，点对话区右上「🎯 四维评分本场对话」，系统会把你本场所有英文应答带到「四维口语实战」中最贴近的场景，再补一步「跟读参考句」即可得到完整的四维分（行业术语发音 / 语调流利度 / 商务应答准确性 / 表达逻辑性）。

> ⚠️ API Key 仅保存在本浏览器 localStorage，不会上传到本站任何服务器，但请勿在公共电脑使用。
> ⚠️ OpenAI 官方接口可能被浏览器跨域（CORS）策略拦截，如报错请改用 DeepSeek 或自定义 CORS 兼容端点。

### 🎯 跟读评测的准确性说明

评测采用「浏览器语音识别 + 逐词对齐」，**识别来源三选一**：

- **浏览器在线**（默认）：Chrome/Edge，依赖 Google（你有 VPN 时走代理）。**分级评分**：精确命中（全分）/ 近似·错拼（部分分，标注 ≈你读的音，如 forward≈fourd）/ 漏读·多读（标红）。
- **本地离线 vosk-browser**：发音设置勾选「优先本地识别」后，跟读评测改用 Kaldi wasm（跨 Safari/Firefox、可断网）。需把解压后的 `models/vosk-model-small-en-us-0.15/` 放到站点根目录、`vosk.js` 放 `js/vendor/`（运行 `tools/fetch-vosk-model.ps1` 一次）；未就绪时自动回退浏览器在线识别。
- **Azure 音素级**（🔎 按钮）：同 Key 打分，见「四维口语实战」。

给出加权准确率 + 精确率，并附针对性练习建议（慢速分音节跟读等）。为获得更高准确度：

- 使用 **Chrome / Edge**（语音识别依赖 Google）。你有 VPN，识别自动走代理；若某次报错，可先点「🔍 诊断语音」确认 Google 可达，或到 Chrome 设置 → 系统 → 开启「使用系统代理」
- 保持环境安静、靠近麦克风、语速放慢；识别失败会自动重试
- 首次使用需允许麦克风权限；误点拒绝时点地址栏左侧麦克风图标改为「允许」后刷新
- 评测分数受口音和识别模型影响，作为**练习参考**而非绝对标准；无法在线识别时可用「录音回放对比」+「听写训练」练习听说

## 🛠 如何扩展内容

所有课程内容集中在 `js/data.js` 中，结构清晰，直接添加即可：

```js
{
  id: 11,                          // 新单元编号
  title: "新单元标题",
  titleEn: "English Title",
  icon: "📦",
  summary: "单元简介",
  vocab: [                         // 词汇：单词 / 音标 / 词性 / 中文 / 例句EN / 例句CN
    { w: "negotiation", ipa: "/nɪˌɡoʊʃiˈeɪʃn/", pos: "n.", cn: "谈判",
      ex: "The negotiation lasted three hours.", exCn: "谈判持续了三个小时。" }
  ],
  phrases: [                       // 短语：短语 / 中文 / 例句EN / 例句CN
    { p: "place an order", cn: "下订单", ex: "We'd like to place an order.", exCn: "我们想下订单。" }
  ],
  dialogues: [                     // 对话：场景标题 + 逐句台词（sp 用 A/B/✉ 区分说话人）
    { title: "场景名", lines: [
      { sp: "A", en: "Good morning!", cn: "早上好！" },
      { sp: "B", en: "Good morning! How can I help you?", cn: "早上好！有什么可以帮您？" }
    ]}
  ],
  tips: ["学习技巧一", "学习技巧二"]
}
```

保存后刷新页面即可生效，无需重新构建。

## 📌 使用提示

- **发音**：右上角 ⚙ 可切换「在线高音质」音源（发音更标准自然，需联网；网络异常自动回退浏览器语音），也可手动选择发音人；首次使用浏览器语音时可能提示下载语音包。
- **录音/评测**：浏览器会弹出麦克风权限请求，请允许；请用「方式一 / 方式三」通过本地服务器访问（`file://` 下语音受限）。智能评测建议 Chrome / Edge。
- **进度**：进度存储在浏览器 localStorage 中，清空浏览器数据会丢失进度。
- **兼容性**：推荐 Chrome / Edge / Firefox 最新版（TTS、录音、语音识别需要较新浏览器）。
