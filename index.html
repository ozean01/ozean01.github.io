软包装外贸英语 v2.0 · 纯静态站点 · 无需服务器

你的学习数据只保存在本浏览器（localStorage），不会上传到本站任何服务器。使用第三方发音 / 语音识别 / AI 陪练接口时，相关语音与文本会发送到对应服务商（详见设置页各接口说明）。

💡 快捷键：单词卡界面按 Space 翻面 🔊 发音使用浏览器自带的语音合成（需联网获取音色时可能首次无声） 本站外语学习与「外贸实操 SOP」内容仅作学习参考，不构成法律/合规/报关专业意见；涉及单据、合规与风险事项请以官方原文与实际业务为准。
⚙️ 发音设置

【最省事·推荐】用 Microsoft Edge 打开本站：在 Edge 设置 → 语音 → 首选发音设为 Online (Natural)，选择「浏览器语音」即可获得接近真人的微软神经网络人声（免费、无需 Key，质量对标 Google 在线语音）。若用 Chrome 想要同等音质，改选「Azure 语音」并填入下方 Key / Region（免费额度，质量旗舰）；「Google 在线音源」为第三方免费端点，常被 Google 封禁而失效，失败时会自动回退浏览器语音，故不再推荐。

填写后在 Azure 门户创建「Speech」资源，复制 Key 与区域填入即可。常见英文人声：en-US-JennyNeural、en-US-AriaNeural、en-US-GuyNeural、en-GB-SoniaNeural。失败时会自动回退浏览器语音。
