软包装外贸英语 纯静态站点 · 无需服务器

你的学习数据只保存在本浏览器（localStorage），不会上传到本站任何服务器。联网功能会向下列服务商发送必要内容——发音朗读（Google 在线音源 / 微软 Azure）、语音识别与音素级评测（Google / 微软 Azure，发送你的录音）、AI 陪练与写作批改（你填写的服务商，默认 DeepSeek；可改为本机 Ollama 从而完全不出本机）、素材投料口抓取网页正文（r.jina.ai，只发送你粘贴的网址）。逐项清单见 ⚙ 设置页「数据去向」。

💡 快捷键：单词卡界面按 Space 翻面 🔊 发音使用浏览器自带的语音合成（需联网获取音色时可能首次无声） 本站外语学习与「外贸实操 SOP」内容仅作学习参考，不构成法律/合规/报关专业意见；涉及单据、合规与风险事项请以官方原文与实际业务为准。
⚙️ 发音设置

【最省事·推荐】用 Microsoft Edge 打开本站：在 Edge 设置 → 语音 → 首选发音设为 Online (Natural)，选择「浏览器语音」即可获得接近真人的微软神经网络人声（免费、无需 Key，质量对标 Google 在线语音）。若用 Chrome 想要同等音质，改选「Azure 语音」并填入下方 Key / Region（免费额度，质量旗舰）；「Google 在线音源」为第三方免费端点，常被 Google 封禁而失效，失败时会自动回退浏览器语音，故不再推荐。

填写后在 Azure 门户创建「Speech」资源，复制 Key 与区域填入即可。常见英文人声：en-US-JennyNeural、en-US-AriaNeural、en-US-GuyNeural、en-GB-SoniaNeural。失败时会自动回退浏览器语音。

外贸场景的用法：同一段材料两种口音各过一遍，适应不同国家买家的发音。站内音标、课程数据与 IPA 审计基线仍全部是美式通用口音 GA —— 换的只是朗读人声。（Azure 引擎若要英音，请把上面的发音人改成 en-GB-SoniaNeural；Google 在线音源固定美音。）

本站不接收任何数据：学习记录（掌握词、单词卡、成绩、作品、打卡）全部只写本机 localStorage，站点没有后端、没有埋点。
下面这些是你主动使用某个联网功能时才会发生的上行：
· 发音朗读（浏览器语音）：在本机合成，不出网。
· 发音朗读（Google 在线音源） → translate.google.com：发送被朗读的英文文本。
· 发音朗读 / 音素级评测（Azure） → <区域>.tts.speech.microsoft.com、<区域>.stt.speech.microsoft.com：发送文本或你的录音 + 你填的订阅 Key。
· 跟读评分 / 语音输入（浏览器在线识别） → Google：发送你的录音（不发送文本）。
· 本地离线识别（vosk，若已就绪）：在本机识别，录音不出网。
· AI 陪练 / 写作批改 / 四维 AI 判分 / 说我想说：发送对话与写作文本到你选择的 Base URL（默认 api.deepseek.com；选 🖥 本地 Ollama 时一步都不出本机）。
· 汇率查询 → cdn.jsdelivr.net：只取公开汇率表，不发送任何个人信息。
· 素材投料口 · 粘贴网页链接 → r.jina.ai：发送你粘贴的那个网址以取回正文（学习数据与 Key 都不会带上）。
关掉对应功能即可停止对应上行；本站不会在你没点的时候主动联网。
